# G34 - D3D feature level 11_0 on the Mali-G76 UMD

User 2026-10-20: "Microphone sounds like a quick-ish win. Make it. ... Then do feature_11 on the GPU."
Brief: parkinglot/fl11-chrome-video.md (why: Chrome/Edge HW video needs FL >= 11_0, FL 11 apps/games).

## Starting point (2026-10-20, Mesa 0198, UMD pipeline level 10_1)
- d3d10umd frontend extended to the D3D11.1 / WDDM 2.0 DDI (Mesa 0070-0081); SM 4.0/4.1 parser + TGSI translator.
- G24: cs_4_x compute (raw/structured buffers, groupshared, one UAV) - Mesa 0111-0119, d3dcs 7/7 vs WARP.
- G25: geometry shaders emulated as compute (GsEmu.cpp, Mesa 0124/0125), panfrost XFB from TGSI fixed.
- G26: BC/ETC2 handling (notes/g26-bc-etc2.md).
- Missing for 11_0 (parking-lot brief): SM5 opcodes, cs_5_0 (typed UAVs, atomics, 8 UAVs, 1024 threads, Z groups),
  PS UAVs, hull/domain shaders (no tessellation hardware on G76), BC6H/BC7, DrawIndirect/DispatchIndirect, 16K textures.
