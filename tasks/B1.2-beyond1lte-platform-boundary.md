# B1.2 — Create the regular-S10 platform configuration boundary

Status: **doing**

## Goal

Create a distinct `Beyond1LtePkg` namespace inside this repository so regular
S10 board facts cannot be confused with the existing S10e `Beyond0LtePkg`.
Do not create a separate repository and do not overwrite S10e constants.

## Work in this task

- Add a board-specific header with source-backed S10 panel, touch, UFS CAL,
  USB-C/PMIC and physical-button facts.
- Add a package README describing the current fail-closed state.
- Do not add a DSC/FDF or enable drivers yet: the S10 memory map, UFS DMA
  aperture and framebuffer handoff are not established.

## Acceptance criteria

- All S10 board constants live outside `Exynos9820.h`; shared SoC MMIO stays
  in the Silicon package.
- No S10e framebuffer, RAM-bank or DMA-window values are copied into the S10
  package.
- Readiness markers default to zero for memory map, UFS DMA, framebuffer,
  USB-C role/power and button electrical configuration.
- The package is explicitly documented as not buildable/flashable yet.

## Next

Trace Samsung boot handoff and memory discovery, then audit UFS DMA/FMP and
USB-C power sequencing before adding a platform DSC.
